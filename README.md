## 📌 Overview

**Bank of Dream World** is a simple ATM simulation project developed using **Python**. It demonstrates the core concepts of Object-Oriented Programming (OOP), GUI development with Tkinter, and banking transaction logic.

The application automatically launches a **Tkinter GUI** when available and falls back to a **console interface** if Tkinter is not installed.

---

## ✨ Features

- 🏦 Create a Bank Account
- 👤 Account Details
- 💰 Deposit Money
- 💸 Withdraw Money
- 📊 Check Balance
- 🧾 Generate Transaction Receipt
- 🎲 Random Transaction ID
- ❌ Insufficient Balance Validation
- 🖥️ Tkinter GUI
- 💻 Console Mode Support

- Check Balance

# 💻 Console Mode

If Tkinter is unavailable, the application automatically switches to Console Mode and provides all ATM functionalities through the terminal.
